源卷唯一键使用 utf8mb4_0900_bin。目标中工作间仍按二进制排序规则区分，票号切换到 utf8mb4_0900_ai_ci。先在真实 MySQL 用目标规则分组，从每组取登记最早、ID 最小的票保留。对其余票用目标唯一索引实际拒绝原号，按固定候选序列预留可用别名。演练表在同一会话隔离并自动清除，只产出交接证据。

试写通过后，制签组在同一卷宗上发布正式新号。准备期间登记的补票与原始工票合并后一起判重；切换前登记的补票都算本次同间判重。发布把整卷编号与发布表头写进同一事务：要么全卷可见，要么完全不可见，技师的按号查询不会看到半卷新号。同卷并发发布由卷行锁串行化，后来者返回已发布的同一套号码；切换中断会整体回滚，重试按同一确定性规则重新算出相同号码。旧票号与工票 ID 的对应关系独立于发布状态，始终可查。
